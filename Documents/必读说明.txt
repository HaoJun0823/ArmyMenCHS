《玩具兵大战》(Army Men) 简体中文补丁  安装说明
================================================

版本
----
本补丁适用于《玩具兵大战》Steam 版（Armymen.exe v1.2.0，1998 年原作的
Steam 再发行版本）。


安装步骤
--------
1. 关闭游戏。若游戏正在运行，请先退出（任务管理器中确认没有 Armymen.exe）。

2. 将本压缩包解压到**游戏根目录**（即 Armymen.exe 所在的文件夹）。
   解压后应当得到这样的结构：

       <游戏目录>\
       ├─ dsound.dll                  <- 新增
       ├─ 必读说明.txt
       ├─ 如果不会安装，请把该文件发给AI，让AI教你.txt
       ├─ 将此文件交给AI，让AI协助完善本项目.txt
       ├─ LICENSE
       ├─ License.txt
       ├─ scripts\
       │   ├─ Army1_Extend_Dll.asi    <- 新增
       │   ├─ ArmyMenCHS.ini          <- 新增
       │   └─ strings\*.ini          <- 新增
       └─ update\
           ├─ Audio\   AVI\   Campaigns\   Maps\   Screens\
           └─ Alpine\  Bayou\  Desert\      <- 新增/覆盖

   选择"替换"（覆盖）所有同名文件。

3. 启动游戏即可。首次启动时游戏目录下会生成 scripts\ArmyMenCHS.log，
   记录汉化加载情况，可用于排查问题。


关于 dsound.dll
--------------
这是 Ultimate ASI Loader（by ThirteenAG，v6.4，MIT 许可）。
它本身不是汉化组件，作用是自动加载 scripts\ 目录下的 .asi 插件。

游戏必须通过它才能加载汉化。如果你的游戏目录里没有这个文件，汉化不会生效。

该文件会用本补丁附带的版本覆盖游戏根目录中已有的同名文件。两者功能一致，
覆盖不会影响游戏正常运行。

如果你希望完全卸载本补丁并恢复干净状态，删除 scripts\ 和 update\ 目录，
以及根目录下的 dsound.dll 即可（如果该文件在安装本补丁之前就存在，
请自行确认来源后再决定是否删除）。


本补丁做了什么
--------------
* 界面文本汉化：菜单、按钮、设置项、武器/单位名称、按键名称等，共 153 条。
  翻译数据存放在 scripts\strings\*.ini，可自行修改后重启生效。

* 中文字体：程序会把游戏的字体创建函数切换到宋体并使用 GB2312 字符集
  （配置见 scripts\ArmyMenCHS.ini 的 [Font] 段）。

* 战略图与地形贴图汉化：update\ 下的资源来自中文零售版，
  并以 Steam v1.2 原版为基底进行合并 —— 只有确实包含中文的资源才替换，
  其余保持 Steam 最新版画质。

* 修复了原中文版的一个 bug：
  高山第三关「羊肠河」绿营地的吉普车会被油桶卡住。
  原因是原中文版的地形数据里，木屋建筑多出一份碰撞掩膜，
  覆盖了本该可通行的地块。本补丁移除了这份多余的掩膜。


本补丁不做什么
--------------
* **不修改 Armymen.exe**。exe 文件保持原样，一个字节都不会变。
  所有补丁内容由 scripts\Army1_Extend_Dll.asi 在游戏运行时于内存中完成，
  卸载后不留任何痕迹。

* 不附带、不分发任何游戏原始素材。
  update\ 下的文件是中文零售版资源块的提取结果，
  请配合你自己合法获取的游戏使用。
