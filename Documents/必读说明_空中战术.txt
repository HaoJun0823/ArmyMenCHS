《玩具兵大战：空中战术》(Army Men: Air Tactics) 简体中文补丁  安装说明
==========================================================================

版本
----
本补丁适用于《玩具兵大战：空中战术》光盘版（amat.exe，2000 年原作光盘版本）。

本作**没有**官方简体中文版。本补丁的界面文本与任务脚本为从零翻译，
中文配音为 TTS 合成（见下文「关于中文配音」）。
本补丁根据这一代游戏的情况施行最小化干预原则，没有大规模修改 UI，
部分界面与位图仍是英文，请见谅。


安装步骤
--------
1. 关闭游戏。若游戏正在运行，请先退出（任务管理器中确认没有 amat.exe）。

2. 将本压缩包解压到**游戏根目录**（即 amat.exe 所在的文件夹）。
   解压后应当得到这样的结构：

       <游戏目录>\
       ├─ dinput.dll                  <- 新增（ASI Loader）
       ├─ ddraw.dll                   <- 新增（cnc-ddraw，已整合）
       ├─ ddraw.ini                   <- 新增（cnc-ddraw 配置，已调好）
       ├─ 必读说明.txt
       ├─ 如果不会安装，请把该文件发给AI，让AI教你.txt
       ├─ 将此文件交给AI，让AI协助完善本项目.txt
       ├─ LICENSE
       ├─ License.txt
       ├─ audio\                      <- 覆盖：codesfx / music / scriptsfx
       ├─ avi\                        <- 覆盖：cine1..cine6.smk（中文片头）
       ├─ scripts\
       │   ├─ Army5_Extend_Dll.asi    <- 新增（汉化运行库）
       │   └─ Hzk16                   <- 新增（中文字库）
       └─ update\
           ├─ audio\voice\*.wav       <- 中文配音
           ├─ bitmaps\  data\  strings\

   选择"替换"（覆盖）所有同名文件。

   ★ 注意 audio\ 与 avi\ 就在**游戏根目录**下，不是 update\ 的子目录。
     这是本作的资源查找方式决定的：update\ 只用来覆盖部分资源，
     音乐/音效与片头动画必须放在根目录的 audio\ 与 avi\ 才会生效。

3. 以**管理员身份**运行游戏（见下文「三条必读提醒」第 3 条）。

4. 启动后，游戏目录下会生成 scripts\ArmyMenAATCHS.log，记录汉化加载情况，
   可用于排查问题。


三条必读提醒
------------
【1】修改键位、音量请在**主界面**改，不要在游戏内改。
      在对局中进入设置界面修改，可能会出现卡顿。原因不在本补丁：
      游戏在枚举系统字体/资源时缺乏约束，会去加载 system32 目录下的
      *_zh-cn.mui 等本地化资源文件，逐个尝试很慢。主界面下改则没有这个问题。

【2】中文配音由 qwen3-tts 独立生成，不是真人录音，也不是声音克隆。
      本作在游戏里**没有**对应的语音字幕，玩家听不出台词内容，
      因此本项目补做了中文语音，用 TTS 尽可能拟合原角色的语气。
      已知不足：
        · 非克隆合成，音色与原版角色有差距；
        · 同一角色的不同台词之间，音色也会有波动。
      如果不喜欢中文配音、或想听回原版英文语音，**直接删除 update\audio
      文件夹**即可（游戏会回落到自带的英文原声），其余汉化不受影响。

【3】游戏已经整合 cnc-ddraw，**不需要**再做兼容模式调整。
      包内已提供 ddraw.dll 与调好的 ddraw.ini，请不要单独删除或替换它们。
      但需要**以管理员模式运行**游戏：
        · 直接运行：右键 amat.exe -> 以管理员身份运行；
        · 从 Steam 启动：右键 amat.exe -> 属性 -> 兼容性 ->
          勾选"以管理员身份运行此程序"，之后从 Steam 启动同样生效。


关于 dinput.dll
---------------
这是 Ultimate ASI Loader（by ThirteenAG，MIT 许可）。
它本身不是汉化组件，作用是自动加载 scripts\ 目录下的 .asi 插件。

游戏必须通过它才能加载汉化。如果你的游戏目录里没有这个文件，汉化不会生效。

为什么用 dinput.dll 而不是别的名字：
本作按**名字**导入 dinput.dll!DirectInputCreateA，用该名字作代理可可靠命中；
换成别的名字，游戏拿不到输入函数，表现是"补丁装了但完全没有效果且不报错"。


关于 ddraw.dll（cnc-ddraw）
--------------------------
本作是 2000 年的 DirectDraw 程序，在新系统上直接运行会出现黑屏、无图像、
鼠标错位等问题。包内的 cnc-ddraw（https://github.com/FunkyFr3sh/cnc-ddraw，
MIT 许可，版本 7.0.0.1）负责把 DirectDraw 调用转到现代渲染后端。

ddraw.ini 已按本作调好，一般不需要改。其中有用的一项：
默认窗口化运行（windowed=true），按 Alt+Enter 可在窗口/无边框全屏之间切换。
窗口大小、是否全屏、缩放方式等都在 ddraw.ini 里，注释为英文，可按需修改。

注意：本补丁的 dinput.dll（ASI Loader）与 ddraw.dll 是两个不同的代理，
互不冲突，但都需要放在游戏根目录。


本补丁做了什么
--------------
* 界面文本汉化：菜单、按钮、设置项、武器/单位名称、按键名称、多人消息、
  难度与确认框等（update\strings\）。

* 取消了游戏检测光盘才能运行的限制，并把相关光盘资源打包入汉化补丁。
  本作的片头动画（avi\cine1..6.smk）与配乐音效（audio\）直接随包提供，
  解压后即可脱离光盘运行。

* 任务与脚本文本汉化：update\data\ 下的关卡脚本、任务 PDA、失败提示、
  阶段性播报。

* 界面贴图汉化：update\bitmaps\ 与 update\data\ 下的中文位图与关卡资源。
  本代**不需要 dat 回包** —— 位图以散文件形式直接覆盖，
  不存在 title.dat / shared.dat 的偏移问题。

* 中文字体：游戏引擎自带点阵字体渲染，本补丁接管其文字绘制调用，
  使用官方中文版（2 代）的 13x13 字库 scripts\Hzk16。

* 长文本换行：中文没有空格，游戏原生的"贪心塞满再回退找空格"断行算法
  遇到长句会整段吞掉。本补丁在断行前按引擎自己的量具重新分句，
  保证插入点永远落在整字边界，不会劈字。

* 中文配音：update\audio\voice\ 下的 wav，由 qwen3-tts 生成
  （详见上文「三条必读提醒」第 2 条）。


本补丁不做什么
--------------
* **不修改 amat.exe**。exe 文件保持原样，一个字节都不会变。
  所有行为由 scripts\Army5_Extend_Dll.asi 在游戏运行时于内存中完成，
  卸载后不留任何痕迹。

* 不附带、不分发任何游戏原始素材。update\、audio\、avi\ 下的内容
  是可覆盖的翻译产物，请配合你自己合法获取的游戏使用。


已知限制
--------
* 部分界面与位图是**烧字**位图（英文直接画在图上），改文本无效，
  本轮未逐一重绘，仍是英文。

* 多人游戏设置配置器是独立的可执行程序，有自己的界面字符串，
  本补丁未汉化。

* 中文配音为 TTS 合成，音色与语气有已知差距（见上文提醒第 2 条）。

* 若出现异常，请把 scripts\ArmyMenAATCHS.log 一并反馈。


卸载
----
删除 scripts\ 与 update\ 目录，以及根目录下的 dinput.dll、ddraw.dll、
ddraw.ini、LICENSE、License.txt、必读说明.txt 与两份 AI 辅助文件即可。

若你另外覆盖了 audio\ 与 avi\，请自行判断是否恢复原文件
（建议安装前备份这两个目录）。

如果 ddraw.dll 在安装本补丁之前就存在于你的游戏目录（即你自己装的 cnc-ddraw），
请先确认来源，再决定是否删除。
