3)   Installation

Insert the Army Men II CD into your CD-ROM drive. When the 
Auto-run screen appears, click on the "Install" button to 
start the installer program. If the Auto-run screen does not 
appear after you insert the CD, click on the Windows "Start" 
button, then choose "Run". Type in the following command at 
the Run prompt (replace the X with your CD-ROM drive letter):

"x:\setup.exe"

Then push the "Enter" key to start installing the game.

4)   Key Features

Here are some key game features that you should keep in mind
while playing the Army Men II game:

The F1 key: If you seem to be stuck on a particular level, 
and are not sure what to do next, make sure to use the F1 
key to check the briefing maps. Objectives will be listed 
on these maps, and should give you a good idea what you 
need to do next.

Shift-click: If you wish to shoot at an inanimate object,
or are having difficulty targeting a particular enemy trooper, 
try holding down the Shift key. This will change the mouse 
cursor to an aiming reticule. If you click the left mouse button
while holding down the Shift key, Sarge will shoot at whatever
the mouse cursor is currently over.

Dropping Items: If Sarge's inventory is full, and you wish
to make room for some other types of Power-Ups, you can have
Sarge drop items. Sarge can drop any items except for his 
Rifle, or any Rifle upgrades (like the Auto-Rifle, Machine
Gun or Vulcan Cannon). Just click on the item that you want 
to drop in the Equipment Array so that it is highlighted, 
then click the "Drop" button in the command panel. The item 
should appear on the ground at Sarge's feet. If you decide 
that you want the original Power-Up after all, you can pick 
it up again just by having Sarge walk over it.

Elitism: Sarge's Troops can gain experience and become more 
effective. Troops gain experience when they destroy enemy 
units, or survive until the end of a mission. When a trooper
goes up a level, they will gain a star. As troops go up 
levels, their weapons will become more powerful, and their 
hit points will increase.

Walking: It is possible to make Sarge and his troops walk,
if you wish to have them move more carefully. You can make
Sarge and any selected troops walk by holding down the ALT,
and then either pressing the "W" key or by holding down the
Mouse1 button.

Command Array: If you find that you want to increase the 
size of the viewable game screen area, it is possible to 
retract the Command Array on the right side of the screen. 
Simply click on the vertical bar on the far right side of 
the screen (the bar that has Sarge's health meter on it), 
and the Command Array will retract. Click on the bar again, 
and the Command Array will expand.

5)   Gameplay Issues 


Single Player Issues
--------------------
1. You may notice that Map 3 (Tank Factory) has three autosave
slots, even though that map only has two missions. Only use the
first autosave if you want to watch the train animation sequence
again. If you just want to play the mission without watching 
the train arrive at the station, load the second autosave.

2. On Map 7 (Isle of Insanity) you will not be able to destroy
the generators until after you have rescued the old man. This 
is intentional; you must complete the mission objectives in order.


Multi-player Issues
-------------------
1. If you play a multi-player game, and use teams, it is possible
to set the game up so that everybody is on the same team. This is
not a bug; it was done intentionally. If you wish to practice 
deploying or fighting on a particular multi-player map without 
actually being at risk, you can do so.

2. If you wish to play a multi-player game on HEAT, MPlayer, or 
MSN, do not start the game first. Either choose the multi-player
service that you want to play on from the Autorun screen, or select
the appropriate shortcut from the Programs menu. The game will be 
started automatically after you have connected to the appropriate
multi-player service's lobby. Also note that you must have the 
game CD in the drive to play as a client on HEAT, Mplayer, or 
MSN. Clients cannot used "spawned" copies of the game while 
playing over these services.

3. Certain multi-player maps (i.e. Run Forrest Run, Graveyard) 
have water on them, but you will not be able to deploy PT Boats 
in the water. These levels were intentionally designed this way.

4. When the Host clicks on the "Start" button to start a 
multiplayer game, there is usually a delay of a few seconds 
before the game actually starts. If the Host repeatedly clicks
on the Start button during this time, they will receive an 
error message in the chat area that will say "Not everybody 
has the same version/map/rules." This error message can be 
somewhat misleading. If the Host clicks on the Start button 
just once and then waits for a few seconds, the game should 
start normally.

6) DirectX(TM) And You

Army Men II uses Microsoft's DirectX API. DirectX depends 
on having up to date hardware drivers for your video card 
and other hardware devices, such as your mouse, sound card 
or network card. If you are having difficulty with Army Men 
displays (screen flickers during game play, Sarge leaving a 
trail of dots) or other hardware (erratic mouse movement or 
choppy sound) try updating your drivers. The latest drivers 
can usually be found on the hardware manufacturer's web site.
If you try updating your drivers and still experience problems, 
please refer to the Customer Support section of the game 
manual, or contact 3DO Customer Support (See the "Contacting
3DO Customer Support" section of this readme).

7) Using HEAT.NET

How to Play on HEAT.net
-----------------------
1) Install HEAT from this CD-ROM

2) For FREE gameplay on HEAT.net, click on the "Play" button 
within the game menu or, from your Java enabled Internet browser,
go to http://www.heat.net.  If you aren't already a HEAT member,
register your account information.  Note, that if you already 
installed the HEAT software from your  Army Men II CD-ROM, 
you will not need to download the software.  (HEAT updates
are automatic.)

3) Log in by entering your user name and password.

4) Choose Army Men II from the list of games

5) Click the "Play Now" button on the web page to get to the 
Army Men II lobby area.

6) From the HEAT Army Men II game lobby, you may choose to 
create a new "room" or join an existing room.  If you 
decide to create a room you will be the moderator, who
controls the game setting options. As the moderator you can
start a game at anytime by clicking the "Launch" button.

Note:  for users with less than 48MB of RAM: Go to the Options
Menu of the HEAT.net Katalyst, click on the General tab, and 
check the box labeled Kill Browser When Game Starts.

8) Using Mplayer

WHAT IS MPLAYER.COM?

Mplayer.com is the #1 multiplayer game service on the Internet.
Playing Army Men II on mplayer.com means that a player in a 
remote location can challenge other players in remote locations,
and they'll play in real time--like they're all sitting in the 
same room. Mplayer.com offers hundreds of innovative features, 
including real-time voice--chat that lets you verbally taunt 
your opponents and praise your teammates. When you sign up for
mplayer.com you're joining a friendly online community where 
you can participate in regular tournaments, contests, and special
events.
 
PRICING

Mplayer.com is FREE--there are no charges or monthly fees to 
play Army Men II on mplayer.com.

SO HOW DO I GET STARTED?

Installing mplayer.com is simple. Just follow these easy steps
and you're on your way to the excitement of online multiplayer 
gaming!


1. There are several ways to install mplayer.com from Army Men II:

From the game CD-ROM Autorun Menu:
- select the option to Play on mplayer.com 
From the Windows 95/98 Start Menu 
- select this game and the option to Play on mplayer.com 
From the Program folder 
- click on the icon to Play on mplayer.com  

2. This will start the mplayer.com installer which will:

Check for mplayer.com -- if you don't have it, we'll install 
everything you need! Just follow the easy install instructions at 
the prompts.  During the process, you'll set up a mplayer.com
account and select your mplayer.com member name and password. 

3. After installing mplayer.com, your Web browser will launch and 
connect you to the mplayer.com game page:
Make sure your game CD-ROM is in the disk drive.
Now click on 'Play Now' to log onto mplayer.com and head to the 
Lobby of your game.
Before entering the game's Lobby, we'll automatically download 
any additional files you might need to make the game playable on 
mplayer.com.

4. Now you are in your game's Lobby on mplayer.com.  
Chat with other players by typing your message and pressing Enter.
To enter a Game Room, double-click on a green Room icon.
If you want to create a new Game Room, click on the Create Room 
button.

5. Almost there!
If you enter an existing Game Room, Click on the 'Ready to Play?'
button, or, If you create a Room, wait for players, then click 
on the 'Launch Game' button.


6. Have fun playing on mplayer.com!
