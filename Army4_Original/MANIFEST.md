# Army4_Original —— World War 英文基线（i18n 精确入库）

> 源：`I:\LocalGames\Army Men\Army Men - World War GOG`
> 生成：`Tools/build_army4_assets.py`（全量 sha256，详见 `_filehash.csv`）

> 校验：`Tools/verify_army4_assets.py`

## 与 Army3_Original 的差别

入库口径**完全相同**（3 代无官方中文母盘，4 代同样无 —— 两代 exe 内 `Hzk16` / `RSE\x1a` 均 0 命中），故本树同样收 `.txt` + `.bmp` + `audio/vos/*.wav`。
4 代与 3 代文本载体**结构同构**（实测：`amww.exe` 内 `strings.txt` 字面量同为 5 处，`Invalid installation` / `wrong number of strings` / `cannot be read` 文案同源，加载器同为 `ExtnText.cpp` 的 `ExtnTextLoad`）。
`audio/vos`（298 个英文台词）入库的原因：它是配音汉化的**对照基线** —— 与将来的 `Army4_Voice_CHS/audio/vos` 同名单一一对应，缺了它就无法核哪句被替换、哪句漏了。
★ `update/` 整目录排除：那是本补丁**安装后**的产物，入库会污染英文基线（详见脚本头部注释）。
★ 根目录 `EULA.txt` 排除：GOG 安装器附带文档，非游戏文本，3 代源目录无此文件。

## 4 代与 3 代的两处实测差异（影响翻译阶段，不影响本树）

| 项 | 3 代 | 4 代 |
|---|---|---|
| `strings/strings.txt` 行数 | 320 行（= 数组容量，零余量） | **323 行** |
| `strings.txt` 下界闸门立即数 | `cmp ..., 320` | `cmp ..., 320`（同） |
| `bitmaps/` 文件数 | 61（`bcs001`/`load_*` 体系） | **65**（`BCS01`/`MAP_01`/`mp_*` 体系） |
| 与 3 代同名 BMP | — | 仅 **5** 个 |

> 注意：3 代「320 行 = 数组容量 = 零余量」的推论**不适用于 4 代**：
> 4 代出厂即 323 行而闸门仍为 320 下界，说明其字符串指针数组容量必然 >= 323。
> 翻译阶段拆行前，必须先用 IDA 实测该数组起点/终点。
