This project ships an ASI Loader that loads scripts\*.asi into the game process. It is the Ultimate ASI Loader (https://github.com/ThirteenAG/Ultimate-ASI-Loader) by ThirteenAG, redistributed unmodified under the MIT License reproduced below.

It is deployed as a proxy DLL in the game root so that the game loads it instead of the system library:

  * Army Men (1)      -> dsound.dll   (proxies the system DSOUND.dll)
  * Army Men II / Toys in Space -> dinput.dll  (proxies the system DINPUT.dll)
